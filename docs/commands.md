# Bedrock WorldEdit v0.3.0 コマンド一覧

| コマンド | 説明 |
|---|---|
| `/bwe:help` | 簡易ヘルプを表示 |
| `/bwe:wand` | 選択専用の木の斧を取得 |
| `/bwe:pos1` | 現在位置を第1地点に設定 |
| `/bwe:pos2` | 現在位置を第2地点に設定 |
| `/bwe:hpos1` | 視線先を第1地点に設定 |
| `/bwe:hpos2` | 視線先を第2地点に設定 |
| `/bwe:size` | 選択範囲のブロック数を確認 |
| `/bwe:desel` | 選択を解除 |
| `/bwe:set <block>` | 指定ブロックで範囲を埋める |
| `/bwe:replace <from> <to>` | 指定ブロックを置換 |
| `/bwe:copy` | 選択範囲をコピー |
| `/bwe:paste [air]` | 現在位置基準で貼り付け。`false`で空気を除外 |
| `/bwe:undo` | 直前の編集を取り消す |
| `/bwe:redo` | 取り消した編集をやり直す |
| `/bwe:history` | 履歴件数を確認 |
| `/bwe:clearhistory` | 自分の履歴を削除 |
| `/bwe:cancel` | 実行中のジョブをキャンセル |

チートが有効なワールドで、メンバー権限以上のプレイヤーが利用できます。
